# Members-Only Resources Management

## Privacy Architecture

**Critical Principle:** NO data should be stored in git. All members-only resources MUST be managed in Supabase database.

## How It Works

1. **Authentication Layer**: Users sign in via Supabase Auth
2. **Membership Verification**: Edge Function `members-resources` checks if user email is in `allowed_members` table
3. **Data Access**: Only authenticated, registered members can fetch resources from `members_resources` table
4. **Zero Data in Code**: No fallback data, placeholders, or sample resources in git/Edge Functions

## Database Tables

### `members_resources`
Stores members-only resources that require authentication to access.

```sql
CREATE TABLE public.members_resources (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title text NOT NULL,
  url text NOT NULL,
  note text,
  sort_order int,
  active boolean NOT NULL DEFAULT true,
  created_at timestamptz NOT NULL DEFAULT now()
);
```

**Fields:**
- `title`: Use format "Topic · Resource Name" to auto-group resources (e.g., "Training · BIM AI Workshop")
- `url`: Full URL to the resource
- `note`: Optional description or context
- `sort_order`: Lower numbers appear first (nulls appear last)
- `active`: Set to `false` to hide without deleting

### `allowed_members`
Controls who can access members-only content.

```sql
CREATE TABLE public.allowed_members (
  email text PRIMARY KEY,
  name text,
  source text,
  metadata jsonb,
  created_at timestamptz NOT NULL DEFAULT now()
);
```

## How to Manage Resources

### Option 1: Supabase Dashboard (Recommended)
1. Go to [Supabase Dashboard](https://supabase.com/dashboard/project/xcctqbamimafkkamuwly/editor)
2. Navigate to **Table Editor** → `members_resources`
3. Click **Insert** → **Insert row**
4. Fill in the fields:
   - **title**: "Training · 2026 AI Workshop Slides"
   - **url**: "https://drive.google.com/..." (restricted access link)
   - **note**: "Workshop materials from Feb 2026"
   - **sort_order**: 10
   - **active**: true
5. Click **Save**

### Option 2: SQL Editor
```sql
INSERT INTO public.members_resources (title, url, note, sort_order, active) 
VALUES 
  ('Training · BIM AI Integration Guide', 'https://drive.google.com/...', 'Step-by-step guide', 1, true),
  ('Templates · 2-Page Submission Template', 'https://docs.google.com/...', 'Use for final submission', 2, true),
  ('Recordings · Feb 2026 Workshop', 'https://youtu.be/...', 'Unlisted YouTube link', 3, true);
```

### Option 3: Python Script (for bulk operations)
```python
import os
from supabase import create_client

url = os.environ.get("SUPABASE_URL")
key = os.environ.get("SUPABASE_SERVICE_KEY")
supabase = create_client(url, key)

resources = [
    {
        "title": "Training · Advanced AI Techniques",
        "url": "https://drive.google.com/...",
        "note": "Restricted access",
        "sort_order": 1,
        "active": True
    }
]

response = supabase.table("members_resources").insert(resources).execute()
```

## Resource Organization

### Using Topics
The title field supports automatic grouping using the format: `Topic · Resource Name`

Examples:
- `Training · BIM AI Workshop Slides`
- `Templates · Submission Guidelines`
- `Recordings · March 2026 Session`
- `Resources · AI Framework Guide`

The UI will automatically:
1. Extract the topic (before the `·`)
2. Create filter buttons for each topic
3. Group resources by topic in the display

### Without Topics
If no `·` is found, resources appear under "All" topic.

## Privacy Best Practices

✅ **DO:**
- Store all links in Supabase `members_resources` table
- Use restricted Google Drive links with access controls
- Use unlisted YouTube links for videos
- Update resources via Supabase Dashboard
- Test with a registered member account

❌ **DON'T:**
- Add data/resources to git commits
- Hardcode URLs in HTML/JavaScript files
- Store placeholder data in Edge Functions
- Commit JSON files with resource data
- Include sensitive links in public documentation

## How Members Access Resources

1. User visits [members.html](https://www.aihackathon.pro/members.html)
2. Signs in with email/password
3. System checks if email is in `allowed_members` table
4. If registered: Shows "Members-Only Resources" section
5. Fetches resources from `members_resources` via Edge Function
6. Displays resources grouped by topic with search/filter

## Error Messages

| Message | Cause | Solution |
|---------|-------|----------|
| "Please sign in to view members-only resources" | Not authenticated | User needs to log in |
| "Signed in, but not registered yet" | Email not in `allowed_members` | Add user to allowlist |
| (No error, section hidden) | `members_resources` table is empty | Add resources via dashboard |
| "Could not load members-only resources" | Server/database error | Check Supabase logs |
